GENAI Q3 - AI-POWERED KNOWLEDGE GRAPH GENERATOR

Files:
- index.html: webpage structure
- style.css: professional white/blue/purple styling
- script.js: sample extraction, triples table, graph drawing, CSV export

HOW TO RUN IN VS CODE:
1. Extract this ZIP file.
2. Open the extracted GenAI_Q3_Knowledge_Graph_Generator folder in VS Code.
3. Open index.html.
4. Right-click inside index.html and choose "Open with Live Server".
   If Live Server is not installed, open index.html directly in Chrome.
5. Edit the source paragraph and click "Generate knowledge graph".
6. Review the triples and use "Export CSV report".

NOTE:
This is a front-end educational demo. Entity extraction uses rule-based sample matching, not a connected generative AI API. Verify every relationship against the original text for the practical requirement.
